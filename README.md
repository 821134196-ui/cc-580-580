# 在线课程证书签发与姓名更正系统

培训平台教务根据学员学习和考试结果签发证书；学员在签发前确认姓名，填写错误后通过申请更正；外部人员可公开核验证书是否有效。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Java 21 · Quarkus 3.15 · Hibernate ORM · SQLite（WAL 模式） |
| 前端 | Svelte 4 + Vite（构建产物由 Quarkus 同源托管） |
| 邮件 | 本地模拟：回执写入 `mail_outbox` 表，前端"邮件回执"页可查 |
| 部署 | 单命令启动，前后端同源（8080 端口） |

## 一键启动

```bash
./start.sh
```

脚本会依次：构建前端 → 拷贝静态资源 → 打包后端 → 启动服务。
打开 http://localhost:8080 即可使用（证书核验页：`/#/verify`）。

> 环境缺少 Java/Maven 时，脚本自动使用 `~/tools` 下的本地工具链。
> 每次启动会重建数据库并载入演示种子数据（`import.sql`）。

## 运行测试

```bash
cd backend && mvn test
```

测试覆盖：**并发签发**（8 线程抢发同一学员 → 仅 1 张有效证；6 学员并发 → 编号互不重复）、
**姓名更正全流程**（退回补件 → 补件重提 → 通过换发 → 旧证作废不可复活）、
**补考后资格重判**、**课程签发后锁定**。

## 端到端演示

服务启动后执行：

```bash
./demo.sh
```

依次演示：① 8 并发抢发仅 1 成功、编号唯一；② 李四补考 78 分后资格实时重判并签发；
③ 更正申请退回补件 → 通过换发 → 旧证核验显示已作废并指向新证。

## 业务规则实现要点

### 资格判定（实时，不用过期快照）
- `EligibilityService.evaluate` 每次调用直接查询当前学时与**最新一次**考试成绩；
- 签发时在同一事务内**再次复核**资格，补考/重修后结果立即变化；
- 证书上保存的成绩/学时仅为展示用快照，不参与后续判定。

### 编号唯一与并发安全（三道防线）
1. 签发门面 `IssuanceFacade` 用应用级公平锁把"复核 + 发号 + 落库 + 提交"整个事务串行化；
2. 发号在事务内先 `UPDATE cert_sequence`（SQLite 写锁），再读序号，格式 `CERT-年份-六位序号`；
3. 数据库兜底：`cert_number` 唯一索引 + `(student_id, course_id) WHERE status='ACTIVE'` 部分唯一索引，
   即使绕过应用锁也不可能出现重复编号或同一学员同一课程两张有效证。

### 姓名更正
- 学员提交申请（更正姓名 + 原因 + 证明材料清单）；
- 教务审核：**材料不足 → 退回补件**（学员补件后重新提交，计提交次数）；**通过 → 同一事务内作废旧证、签发新证**（版本 +1，链式关联）；**拒绝 → 记录原因**；
- 旧证状态置为 `REVOKED` 后**没有任何代码路径可以恢复**（无重新激活接口，对已作废证书申请更正返回 409）；
- 更正原因、材料、审核意见随申请单永久保留，证书版本页完整展示。

### 课程信息保护
- 已签发过证书的课程，`PUT /api/courses/{id}` 返回 409，课程信息不可再修改；
- 证书上的课程信息以签发时快照保存。

### 公开核验
- `GET /api/verify/{certNumber}` 无需登录：有效 → 持证人与课程；已作废 → 作废时间、原因、替代证书编号；不存在 → 明确提示。

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/eligibility?studentId&courseId` | 实时资格判定 |
| POST | `/api/certificates/issue` | 教务签发（携带学员确认姓名） |
| GET | `/api/certificates` / `/{id}` / `/{id}/chain` | 证书列表 / 详情 / 版本链 |
| POST | `/api/corrections` | 提交更正申请 |
| POST | `/api/corrections/{id}/return` `/resubmit` `/approve` `/reject` | 审核与补件 |
| GET | `/api/verify/{certNumber}` | 公开核验 |
| PUT | `/api/records/study` · POST `/api/records/exam` | 学时维护 / 成绩登记（补考） |
| GET | `/api/mails` | 模拟邮件发件箱 |

```
└── frontend/           # Svelte 前端（教务工作台、证书版本页、更正、核验、邮件）
```
